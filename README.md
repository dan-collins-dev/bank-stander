# BankStander

### Project Overview

BankStander is a small app that lets Old School RuneScape free-to-play players monitor up-to-date price information for items and log their transactions to provide insights on their profit/loss margins and wealth accumulation.

## How to run this project

### Required Tools
- [NodeJS v22+](https://nodejs.org/)

#### Clone Project

Open a terminal and run:

  ```bash
  git clone https://github.com/dan-collins-dev/bank-stander.git
  cd bank-stander
  ```

Open two new terminals in the `bank-stander` project directory. One will run the front-end while the other runs the back-end.

#### Back-End

```bash
cd backend
npm install
npm run dev    # http://localhost:8000
```

#### Front-End

```bash
cd frontend
npm install
npm run dev    # http://localhost:5173 
```
